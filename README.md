# 🥗 Protein Daily

Um aplicativo simples e intuitivo para acompanhar o consumo diário de proteínas e auxiliar no planejamento alimentar de quem busca ganhar massa muscular.

## 📌 Sobre o projeto

O **Protein Daily** permite registrar os alimentos consumidos ao longo do dia, estimar a quantidade de proteína ingerida e acompanhar o progresso em relação a uma meta diária.

A proposta é oferecer uma ferramenta prática, com uma interface limpa e fácil de usar, sem a necessidade de cadastro ou instalação.

## ✨ Funcionalidades

- **Acompanhamento diário:** visualização da quantidade de proteína consumida e da meta estabelecida.
- **Meta personalizada:** possibilidade de ajustar a quantidade diária de proteína desejada.
- **Registro por refeições:** organização dos alimentos em café da manhã, almoço, lanche, jantar e ceia.
- **Busca de alimentos:** seleção de alimentos a partir de uma base de dados integrada.
- **Cálculo automático:** estimativa da quantidade de proteína de acordo com o alimento e a porção informada.
- **Armazenamento local:** os registros ficam salvos no navegador, sem necessidade de criar uma conta.
- **Limpeza dos registros:** possibilidade de apagar os registros do dia.

## 🚀 Como utilizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `protein_daily.html` no navegador.
3. Defina sua meta diária de proteína.
4. Clique na refeição desejada para adicionar alimentos.
5. Selecione o alimento, informe a quantidade e a unidade de medida.
6. Acompanhe seu progresso ao longo do dia.

Não é necessário instalar dependências ou executar um servidor.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage API

O projeto utiliza tecnologias nativas da web e funciona diretamente no navegador.

## 💾 Armazenamento de dados

Os registros são armazenados localmente por meio do `localStorage` do navegador.

Isso significa que:
- Não é necessário cadastro ou login.
- Os dados permanecem salvos entre acessos no mesmo navegador.
- Os registros não são sincronizados entre dispositivos.
- A limpeza dos dados do navegador pode ocasionar a perda dos registros.

## ⚠️ Sobre os valores nutricionais

As quantidades de proteína apresentadas são estimativas baseadas em valores nutricionais médios.

Os valores podem variar conforme a marca, o preparo e as características de cada alimento. Para maior precisão, consulte as informações nutricionais dos produtos utilizados.

O aplicativo tem finalidade de organização e acompanhamento alimentar, não substituindo a orientação de um nutricionista.

## 🎯 Objetivo

Criar uma ferramenta acessível e funcional para facilitar o acompanhamento do consumo de proteínas na rotina de quem pratica musculação e busca desenvolver massa muscular.
